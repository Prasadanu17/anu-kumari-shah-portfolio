# Anu Kumari Shah — Portfolio (Monorepo)

Full-stack portfolio project with separate frontend and backend.

## Structure
- frontend/ — React + Vite portfolio
- backend/ — Node.js + Express + MongoDB API

## Quick Start

### Backend
cd backend
npm install
npm run seed
npm run dev

### Frontend
cd frontend
npm install
npm run dev

## Tech Stack
Frontend: React, Vite, Tailwind CSS
Backend: Node.js, Express, TypeScript, MongoDB, JWT
